# 📋 Система учёта лекарственных средств

Веб-приложение для руководителя выездного подразделения с интеграцией Google Sheets через Apps Script Web App.

## 🚀 Быстрый старт

### 1. Создайте Google таблицу

1. Перейдите в [Google Sheets](https://sheets.google.com)
2. Создайте новую таблицу
3. Откройте **Расширения → Apps Script**
4. Удалите весь код в редакторе
5. Вставьте код из файла `public/google-apps-script-webapp.js`
6. Сохраните проект (Ctrl+S)
7. Выполните функцию `setupDatabase()`:
   - Выберите функцию из выпадающего списка
   - Нажмите кнопку ▶ (Выполнить)
   - Авторизуйте доступ при запросе
8. Дождитесь создания всех листов (11 листов)

### 2. Разверните как веб-приложение

1. В Apps Script нажмите **Развернуть → Новое развертывание**
2. Настройки:
   - **Тип**: Веб-приложение
   - **Описание**: Система учёта лекарств (или любое)
   - **Выполнять от имени**: Меня (ваш email)
   - **Доступ**: Все (или "Все, у кого есть ссылка")
3. Нажмите **Развернуть**
4. Скопируйте URL веб-приложения (начинается с `https://script.google.com/macros/s/...`)

### 3. Подключите приложение

1. Откройте веб-приложение
2. Вставьте скопированный URL в поле
3. Нажмите **Подключиться**
4. Готово! Приложение загрузит данные из Google Sheets

## ✅ Преимущества этого подхода

- **Не требует Google Cloud Console** — работает в любой стране
- **Не требует API ключей** — используется только Google аккаунт
- **Бесплатно** — нет ограничений по запросам
- **Просто настроить** — всего 3 шага
- **Безопасно** — данные хранятся в вашем Google аккаунте

## 📊 Структура базы данных

Приложение использует 11 листов в Google Sheets:

| Лист | Описание |
|------|----------|
| **Сотрудники** | Данные сотрудников, статусы, контакты |
| **Номенклатура** | Справочник лекарств, оборудования, расходников |
| **Цены** | История цен с версионностью |
| **Приход** | Поступление препаратов на сотрудника |
| **Расход** | Расход по каждому пациенту |
| **Возвраты** | Операции возврата на склад |
| **Начальные остатки** | Остатки при первом подключении |
| **Чат** | Сообщения между участниками |
| **Журнал изменений** | Аудит всех действий |
| **Настройки** | Системные параметры |
| **Отчёты** | Сформированные отчёты |

## 🎯 Основные функции

### Для руководителя

- **📊 Панель управления** — общая статистика, уведомления, сводка по сотрудникам
- **👥 Сотрудники** — управление сотрудниками, добавление, блокировка
- **💊 Номенклатура** — справочник препаратов и оборудования
- **📋 Операции** — приход, расход, возвраты
- **📦 Остатки** — расчёт остатков в штуках и рублях
- **💬 Сообщения** — чат с сотрудниками
- **📈 Отчёты** — ежемесячные отчёты, экспорт в CSV
- **📝 Журнал** — история всех изменений

### Автоматические уведомления

- ⚠️ Перерасход у сотрудника (расход > приход)
- 🔴 Сотрудник не вносит расход 7+ дней
- ↩️ Новые возвраты от сотрудников
- 💬 Новые сообщения

## 🔧 Технологии

- **Frontend**: React 18, TypeScript, Tailwind CSS, Vite
- **Backend**: Google Apps Script Web App
- **Хранилище**: Google Sheets + localStorage (для конфигурации)

## 💾 Хранение данных

- **Конфигурация** (URL веб-приложения) — в localStorage браузера
- **Все данные** — в Google Sheets таблице
- **Автоматическая синхронизация** при каждом действии

## 🔐 Безопасность

Если нужно обновить логику Apps Script:

1. Откройте таблицу → Расширения → Apps Script
2. Замените код на новую версию из `public/google-apps-script-webapp.js`
3. Сохраните
4. Создайте новое развертывание (или обновите существующее)
5. Скопируйте новый URL (если изменился)
6. Обновите URL в настройках приложения

## 🤝 Поддержка

При возникновении проблем:

1. **Ошибка подключения**:
   - Проверьте правильность URL
   - Убедитесь, что Apps Script развернут как веб-приложение
   - Проверьте доступ: "Все" или "Все, у кого есть ссылка"

2. **Ошибка выполнения setupDatabase()**:
   - Проверьте, что вы авторизованы в Google аккаунте
   - Попробуйте выполнить функцию повторно
   - Проверьте консоль Apps Script на наличие ошибок

3. **Данные не загружаются**:
   - Проверьте, что все листы созданы
   - Убедитесь, что URL актуальный
   - Проверьте консоль браузера (F12) на наличие ошибок
