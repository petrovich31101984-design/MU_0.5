# 📋 Система учёта лекарственных средств

Веб-приложение для руководителя выездного подразделения с интеграцией Google Sheets.

## 🚀 Быстрый старт

### 1. Получите API ключ Google Cloud

1. Перейдите в [Google Cloud Console](https://console.cloud.google.com)
2. Создайте новый проект или выберите существующий
3. Включите **Google Sheets API**:
   - Перейдите в "APIs & Services" → "Library"
   - Найдите "Google Sheets API"
   - Нажмите "Enable"
4. Создайте API ключ:
   - Перейдите в "APIs & Services" → "Credentials"
   - Нажмите "Create Credentials" → "API Key"
   - Скопируйте ключ (начинается с `AIzaSy...`)

### 2. Создайте Google таблицу

1. Перейдите в [Google Sheets](https://sheets.google.com)
2. Создайте новую таблицу
3. Откройте **Расширения** → **Apps Script**
4. Удалите весь код в редакторе
5. Вставьте код из файла `public/google-apps-script.js`
6. Нажмите **Выполнить** (▶) → выберите функцию `setupDatabase`
7. Авторизуйте доступ при запросе
8. Дождитесь создания всех листов (11 листов)
9. Скопируйте **ID таблицы** из URL:
   ```
   https://docs.google.com/spreadsheets/d/ID_ТАБЛИЦЫ/edit
   ```

### 3. Настройте доступ к таблице

1. Откройте таблицу в Google Sheets
2. Нажмите кнопку **Настройки доступа** (справа вверху)
3. Измените доступ: **"Все, у кого есть ссылка"** → **Читатель**
4. Нажмите **Готово**

### 4. Подключите приложение

1. Откройте веб-приложение
2. Введите **API ключ** и **ID таблицы**
3. Нажмите **Подключиться**
4. Готово! Приложение загрузит данные из Google Sheets

## 📊 Структура базы данных

Приложение использует 11 листов в Google Sheets:

| Лист | Описание |
|------|----------|
| **Сотрудники** | Данные сотрудников, статусы, контакты |
| **Номенклатура** | Справочник лекарств, оборудования, расходников |
| **Цены** | История цен с версионностью |
| **Приход** | Поступление препаратов на сотрудника |
| **Расход** | Расход по каждому пациенту |
| **Возвраты** | Операции возврата на склад |
| **Начальные остатки** | Остатки при первом подключении |
| **Чат** | Сообщения между участниками |
| **Журнал изменений** | Аудит всех действий |
| **Настройки** | Системные параметры |
| **Отчёты** | Сформированные отчёты |

## 🎯 Основные функции

### Для руководителя

- **📊 Панель управления** — общая статистика, уведомления, сводка по сотрудникам
- **👥 Сотрудники** — управление сотрудниками, добавление, блокировка
- **💊 Номенклатура** — справочник препаратов и оборудования
- **📋 Операции** — приход, расход, возвраты
- **📦 Остатки** — расчёт остатков в штуках и рублях
- **💬 Сообщения** — чат с сотрудниками
- **📈 Отчёты** — ежемесячные отчёты, экспорт в CSV
- **📝 Журнал** — история всех изменений

### Автоматические уведомления

- ⚠️ Перерасход у сотрудника (расход > приход)
- 🔴 Сотрудник не вносит расход 7+ дней
- ↩️ Новые возвраты от сотрудников
- 💬 Новые сообщения

## 🔧 Технологии

- **Frontend**: React 18, TypeScript, Tailwind CSS, Vite
- **Backend**: Google Sheets API v4
- **Хранилище**: Google Sheets + localStorage (для конфигурации)

## 💾 Хранение данных

- **Конфигурация** (API ключ, ID таблицы) — в localStorage браузера
- **Все данные** — в Google Sheets таблице
- **Автоматическая синхронизация** при каждом действии

## 🔐 Безопасность

⚠️ **Важно**: API ключ хранится в localStorage и виден в коде приложения.

Для продакшена рекомендуется:
1. Ограничить API ключ только для Google Sheets API
2. Ограничить доступ по HTTP referrers (только ваш домен)
3. Использовать серверный прокси для скрытия ключа
4. Регулярно ротировать ключи
