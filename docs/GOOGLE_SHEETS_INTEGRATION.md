# Интеграция с Google Sheets API

## Обзор

Система учёта лекарственных средств интегрирована с Google Sheets API для хранения и синхронизации данных. Это позволяет использовать Google Sheets как базу данных для всех приложений (веб-приложение руководителя, веб-приложение кладовщика, мобильное приложение сотрудников).

## Компоненты интеграции

### 1. Google Sheets Service (`src/services/googleSheets.ts`)

Сервисный слой для работы с Google Sheets API.

**Основные функции:**

- `setConfig(apiKey, spreadsheetId)` - установка конфигурации
- `testConnection()` - проверка подключения
- `readSheet(sheetName)` - чтение данных из листа
- `writeToSheet(sheetName, values)` - запись данных в лист
- `updateCell(sheetName, cell, value)` - обновление ячейки
- `getSheetsList()` - получение списка листов

**Специализированные методы:**

- `readEmployees()` - чтение сотрудников
- `readNomenclature()` - чтение номенклатуры
- `readPrices()` - чтение цен
- `readArrivals()` - чтение прихода
- `readExpenses()` - чтение расхода
- `readReturns()` - чтение возвратов
- `readChat()` - чтение чата
- `addEmployee(employee)` - добавление сотрудника
- `addExpense(expense)` - добавление расхода
- `addArrival(arrival)` - добавление прихода
- `addReturn(returnOp)` - добавление возврата
- `addChatMessage(message)` - добавление сообщения
- `addAuditLog(log)` - добавление записи в журнал

### 2. Data Adapter (`src/services/dataAdapter.ts`)

Адаптер для работы с данными из Google Sheets или mock-данными.

**Особенности:**

- Автоматическое переключение между реальными данными и mock-данными
- Единый интерфейс для всех операций с данными
- Обработка ошибок с fallback на mock-данные
- Трансформация данных из формата Google Sheets в формат приложения

**Использование:**

```typescript
import { dataAdapter } from './services/dataAdapter';

// Получить сотрудников
const employees = await dataAdapter.getEmployees();

// Добавить расход
await dataAdapter.addExpense({
  id: 'EXP-001',
  employeeId: 'EMP-001',
  nomenclatureId: 'NOM-001',
  quantity: 5,
  patientName: 'Иванов И.И.',
  // ...
});
```

### 3. React Hook (`src/hooks/useGoogleSheets.ts`)

Хук для управления состоянием подключения в React компонентах.

**Использование:**

```typescript
import { useGoogleSheets } from './hooks/useGoogleSheets';

function MyComponent() {
  const { config, loading, error, connect, disconnect } = useGoogleSheets();
  
  const handleConnect = async () => {
    const success = await connect(apiKey, spreadsheetId);
    if (success) {
      console.log('Подключено!');
    }
  };
  
  return (
    <div>
      {config.connected ? 'Подключено' : 'Не подключено'}
      <button onClick={handleConnect}>Подключиться</button>
    </div>
  );
}
```

## Настройка подключения

### Шаг 1: Создание таблицы Google Sheets

1. Перейдите на [sheets.google.com](https://sheets.google.com)
2. Создайте новую таблицу
3. Выполните скрипт установки базы данных (вкладка "Установка БД" в приложении)
4. Скопируйте ID таблицы из URL:
   ```
   https://docs.google.com/spreadsheets/d/ID_ТАБЛИЦЫ/edit
   ```

### Шаг 2: Получение API ключа

1. Перейдите в [Google Cloud Console](https://console.cloud.google.com)
2. Создайте новый проект или выберите существующий
3. Включите Google Sheets API:
   - Перейдите в "APIs & Services" → "Library"
   - Найдите "Google Sheets API"
   - Нажмите "Enable"
4. Создайте API ключ:
   - Перейдите в "APIs & Services" → "Credentials"
   - Нажмите "Create Credentials" → "API Key"
   - Скопируйте ключ

### Шаг 3: Настройка доступа к таблице

**Вариант 1: Публичный доступ (для тестирования)**

1. Откройте таблицу в Google Sheets
2. Нажмите "Share" (Поделиться)
3. Измените доступ на "Anyone with the link" (Все, у кого есть ссылка)
4. Установите права "Viewer" (Просмотр)

**Вариант 2: Сервисный аккаунт (для продакшена)**

1. Создайте сервисный аккаунт в Google Cloud Console
2. Скачайте JSON ключ сервисного аккаунта
3. Предоставьте доступ к таблице email сервисного аккаунта
4. Используйте серверный прокси для безопасной работы с API

### Шаг 4: Подключение в приложении

1. Откройте приложение
2. Перейдите в раздел "Google Sheets" (в боковом меню)
3. Введите API ключ и ID таблицы
4. Нажмите "Подключиться"
5. Проверьте статус подключения (зелёный индикатор)

## Режимы работы

### 1. Режим mock-данных (по умолчанию)

- Используется, когда Google Sheets не подключен
- Все данные хранятся в памяти приложения
- При перезагрузке страницы данные сбрасываются
- Подходит для демонстрации и тестирования

### 2. Режим реальных данных

- Активируется после подключения к Google Sheets
- Все данные читаются из Google Sheets
- Изменения записываются в Google Sheets
- Данные сохраняются между сессиями
- Подходит для продакшена

### 3. Гибридный режим (будущее улучшение)

- Чтение из Google Sheets
- Запись в локальный кэш (IndexedDB)
- Фоновая синхронизация с Google Sheets
- Работа в офлайн-режиме

## Обработка ошибок

### Типичные ошибки и решения

**Ошибка: "API key not valid"**
- Проверьте правильность API ключа
- Убедитесь, что Google Sheets API включен
- Проверьте, что ключ не истёк

**Ошибка: "Permission denied"**
- Проверьте доступ к таблице
- Убедитесь, что таблица доступна по ссылке
- Для сервисного аккаунта проверьте права доступа

**Ошибка: "Sheet not found"**
- Убедитесь, что таблица создана
- Проверьте названия листов (должны совпадать с ожидаемыми)
- Выполните скрипт установки базы данных

**Ошибка: "Quota exceeded"**
- Google Sheets API имеет лимиты (60 запросов/минуту)
- Оптимизируйте запросы (batch operations)
- Используйте кэширование

## Безопасность

### Рекомендации

1. **Не храните API ключ в коде**
   - Используйте переменные окружения
   - Для клиентских приложений - серверный прокси

2. **Ограничьте API ключ**
   - Только для Google Sheets API
   - Только для конкретного приложения (HTTP referrers)
   - Только для чтения/записи конкретной таблицы

3. **Используйте сервисный аккаунт для продакшена**
   - Более безопасный, чем API ключ
   - Не требует хранения ключа на клиенте
   - Поддерживает тонкую настройку прав доступа

4. **Регулярно ротируйте ключи**
   - Создавайте новые ключи периодически
   - Удаляйте старые ключи
   - Мониторьте использование ключей

## Производительность

### Оптимизация запросов

**Плохо:**
```typescript
// 100 отдельных запросов
for (const employee of employees) {
  await googleSheetsService.updateCell('Сотрудники', `E${row}`, 'Активен');
}
```

**Хорошо:**
```typescript
// Один batch запрос
const values = employees.map(e => [e.status]);
await googleSheetsService.writeToSheet('Сотрудники', values, 'E2:E101');
```

### Кэширование

```typescript
// Кэширование данных в памяти
let cachedEmployees = null;
let cacheTime = 0;
const CACHE_DURATION = 30000; // 30 секунд

async function getEmployees() {
  const now = Date.now();
  if (cachedEmployees && now - cacheTime < CACHE_DURATION) {
    return cachedEmployees;
  }
  
  cachedEmployees = await dataAdapter.getEmployees();
  cacheTime = now;
  return cachedEmployees;
}
```

## Мониторинг и логирование

### Логирование операций

Все операции с Google Sheets логируются в консоль:

```typescript
console.log('Чтение листа:', sheetName);

```

## Поддержка

5. Обратитесь к документации Google Sheets API
